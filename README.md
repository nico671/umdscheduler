# UMDScheduler

UMDScheduler is a course-planning tool for University of Maryland students. It
turns a list of classes into schedule options that fit the student's time,
credit, seat, and instructor preferences.

![Alt Text
](screenshots/dashboard.png)

## What it does

UMDScheduler helps students explore course options before they register. They
can search the course catalog, review each section, and create schedules that
do not overlap.

The planner can also account for:

- required and optional classes;
- time periods that a student cannot attend;
- instructors a student wants to avoid;
- a target credit range; and
- sections that still have open seats.

Each result appears in a weekly calendar. Students can compare the class
times, sections, and available instructor and course information before they
choose a schedule.

## How to use it

1. Go to [UMDScheduler](https://umdscheduler.vercel.app).
2. Search for a course by code, title, or GenEd requirement.
3. Add classes to your required or optional list. Set any time, credit, seat,
   or instructor preferences.
4. Select **Generate schedules** and compare the calendar results.

## A planning aid, not an enrollment system

UMDScheduler helps with schedule planning. It does not register students for
classes. Course availability and requirements can change, so students should
confirm final details in the University's official registration tools.

## Built for UMD students

The project brings course and section information into one focused planning
experience. It also presents instructor ratings and grade information, when
available, to help students compare options. These details are useful context,
not a guarantee of a student's experience or outcome.
